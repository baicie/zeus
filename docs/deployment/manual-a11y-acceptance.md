# Zeus 0.2.0 人工 A11y 验收包

状态：`NOT_RUN`。自动化三引擎与 axe 扫描不能替代屏幕阅读器人工验收。
本文件供验收人填写；未签署前不得标记 PASS。

## 通用准备

- 使用隔离验收账号与测试数据，不使用真实用户数据。
- 记录浏览器/OS/辅助技术版本、验收人、日期、commit 与部署 URL。
- 每个产品至少覆盖：VoiceOver + Safari、NVDA + Chrome、NVDA + Firefox。
- 证据保存到 `temp/a11y/<product>/`（截图/录像/文字记录）。

## WebC Studio / Native Lab

入口：`/`（Native Lab）与 `/webc.html`（WebC Studio）。

1. 键盘 Tab 到编辑器、Compile、预览 iframe、导出按钮；顺序应符合视觉顺序。
2. 在编辑器中用键盘输入并触发编译；错误诊断应可被屏幕阅读器读出。
3. 预览 iframe 内的按钮可通过键盘聚焦并触发；焦点不应逃逸到 host 页面。
4. 打开/关闭 React + Vue host 预览；焦点应回到触发按钮。
5. 200% 缩放与 375px 宽度下编辑器、预览、工具栏不重叠且可滚动。
6. 高对比度/减少动态效果下不丢失信息。

预期：所有交互可达；编译错误与预览状态有可读文本；无键盘陷阱；无水平溢出。

## Zeus Admin

入口：`/admin/users`（登录后）。

1. 仅用键盘完成登录、退出、搜索、分页、行选择与编辑。
2. 打开用户编辑 Dialog：焦点进入、Escape 关闭、关闭后焦点回到触发元素。
3. 提交空表单，确认错误消息被屏幕阅读器播报并与字段关联。
4. Data Grid：方向键移动、Enter 选择、分页按钮可达。
5. viewer 角色尝试写入，确认被拒绝且有可读错误。
6. 200% 缩放与移动端布局下表格可横向滚动，操作按钮不被裁切。

## AI Workbench

入口：`/`（Replay/Reference 模式）。

1. 键盘发送消息；流式回复应有适当的 live region 播报，不应逐字轰炸。
2. 打开审批提示，Tab 到 Approve/Reject，Escape 不丢失待审批状态。
3. 打开 Diff Viewer 与 Test Report；标题、文件树与结果可被读出。
4. 附件选择、会话切换、新建会话均可键盘完成。
5. 断开网络/停止流后恢复，状态与审批不被重复播报。
6. 200% 缩放与移动端下 composer 与消息时间线可操作。
