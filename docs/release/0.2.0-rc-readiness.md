## 0. 判定

# NO-GO

**代码本身没有阻塞项。** 16 个子系统的回归全部通过；packed consumers 在 Node 24 下 38/38 通过；
对话框在完全独立的工程里三引擎 6/6 通过；跨平台证据真实存在且校验零错误。

阻塞的是**发布链路的可追溯性与三项必须由维护者完成的动作**：

1. 生产镜像的 `uiCommit` 记录是错的（P0）
2. npm 上没有含对话框修复的版本（P0）
3. 版本未切到 `0.2.0-rc.0`（流程步骤，非缺陷）
4. 发布审批不存在（工作流零运行 + `Release` 环境无保护规则）
5. 在线产品验收未执行
6. 人工签核未完成

按规则，「包不可复现、版本不一致、重要测试证据缺失」是 NO-GO 判据。本轮命中 1、2、4、5。

**不把 BLOCKED 或 NOT_RUN 改写成 PASS。**

## 6. Demo pairing 是这一轮唯一完全干净的一项

`demos-pages.yml` 在 push 时的实际日志：

```
--ui-commit "89fc93cac5b97f29f48deb64964886476c5d7aac"
Set output 'ui-commit'
```

**与冻结 SHA 一致。** 这是「合并 main 会部署」这条链路上唯一一个配对正确的工作流——
因为它用 `git fetch` 把 ref 解析成 SHA 再 checkout，而不是依赖一个未配置的变量。

## 9. `check:rc-readiness` 的准确解读

本轮运行（Node 24.16.0）：

```text
NOT_READY
- clean-worktree: working tree has uncommitted changes
- cross-platform:      rc-evidence.json missing
- release-approval:    rc-evidence.json missing
- online-products:     rc-evidence.json missing
```

四项中有三项是「组装文件缺失」，而不是「证据缺失」：

- `cross-platform` 文档**已存在且校验通过**，只是没放进 `temp/release/`；
- `release-approval` 与 `online-products` 是**真的没有**；
- `clean-worktree` 是因为正在写这份文档。

**因此 readiness 的 NOT_READY 不能直接当成「三项证据都没有」。** 这一区分是本轮的重点之一。

## 11. 部署与回滚

见 `0.2.0-rc-deployment-events.md` 与 `0.2.0-rc-rollback-plan.md`。

**核心事实：合并 main 就会部署。** 三个 Core 工作流 + 一个 UI 工作流都以 `push: [main]` 触发，路径过滤含 `packages/**`。

**本轮建议：不回滚。** 当前三个站点的产物是正确的（线上 dialog chunk 含修复标记），
回滚只会把正确的产物换掉。需要修的是**记录**，不是**产物**。

## 12. 判定的依据

| 结论           | 定义                                                            | 是否符合         |
| -------------- | --------------------------------------------------------------- | ---------------- |
| GO             | 无阻断项                                                        | 否               |
| CONDITIONAL GO | 无 P0，有已记录的 P1                                            | 否 — **存在 P0** |
| **NO-GO**      | 存在 P0 / 包不可复现 / 版本不一致 / 关键门禁失败 / 重要证据缺失 | **是**           |

命中判据：

1. **存在 P0**：P0-1（生产溯源错误）、P0-2（dialog 未发布）
2. **发布关键门禁失败**：`check:rc-readiness` NOT_READY
3. **重要证据缺失**：release-approval 零运行、online-products 未执行
