## 5. 本轮发现的自身错误

UI 的 `package.json` 里，上一轮加进的 `"release:rc-manifest": "tsx scripts/release/rc-manifest.ts"` 指向一个 UI 仓**不存在**的文件。manifest 生成器在 Core。

已确认这不是我的本轮改动（本轮未动 UI 工作区），是上一轮遗留。**它必须被删除或补上实现**，否则 `pnpm release:rc-manifest` 在 UI 仓会失败。本轮不修改它——任务禁止改业务源码，而这是一处需要维护者决定归属的修补。
