## 亮点

### 响应式运行时

- **`ref` 回调在响应式追踪之外执行**。此前 ref 回调里读取的 signal 会被记为依赖，导致
  "创建表单时读了字段值 → 字段值变化 → 表单重建"这类难以定位的重建。这是 Admin 表单
  `PATCH {}` 问题的根因。
- Jsx 兄弟节点不再互相消耗嵌套预算，深层结构不再被误判为超限。

### 编译器

- 嵌套预算按兄弟关系计算，而不是按累计深度。
- Playground 的循环预算不再杀死合法代码，只在真正失控时停止。

### Web Components

- `zw-dialog` 的受控/非受控语义明确化：模式在 setup 时判定一次并记录在元素上，投影重建后继承。
  此前未受控对话框会把自己变成"没人控制的受控对话框"，表现为关不掉。
- Escape 与焦点陷阱移到 `document` 级，WebKit 上焦点不再逃出模态。
- 一次 Escape 只关闭一层嵌套对话框；焦点候选过滤掉无盒子、`inert`、`visibility: hidden` 的控件。

### i18n

- 新增 `@zeus-js/i18n`：带类型、响应式的 ICU 运行时，可选安装。
- Playground 与 Admin 接入共享运行时；语言切换后持久化。

### 构建与发布

- 体积门禁修复：此前读取的字段从不存在，恒报 0 MB 放行。修复后真实限制生效。
- `@zeus-js/i18n` 注册进 fixed 发布组。
- 脚手架 CLI 使用绝对上限，不再随工作区体积漂移。

### 演示与部署

- Admin 只读预览发布到 GitHub Pages。
- **双仓配对**：`demo-pairing.json` 记录 Core 与 UI 的完整 SHA、构建时间、各产物摘要与站点
  摘要，并由 `--verify --reproducible` 在发布前校验。
- Admin 镜像的发布拆成 build / mirror / deploy 三段，TCR 复制在 job 预算内完成。
- Admin 控制台按 shadcn-admin 重建；Gallery 页面渲染真实的 `zw-*` 组件。

### AI Workbench（UI）

- **Search chats 真正可用**：过滤本地 BYOK 会话与有权限的 Host 会话；无匹配时显示真实空态。
- 代码块语法着色。
- 移动端对照截图与参考同分辨率、同主题、同页面状态。

## 破坏性变更

### 1. 版本号跃迁

`0.1.1-beta.20` → `0.2.0-rc.0`（Core 32 包）、`0.1.0-beta.35` → `0.2.0-rc.0`（UI 46 包）。

peer 关系是**精确版本**：每个 `@zeus-web/*` 组件把 `@zeus-js/zeus` 钉在具体版本。因此 Core 与 UI
必须按序发布，不能单独升级其一。

### 2. `zw-dialog` 的 `open` 语义

未受控对话框在状态未被显式设置前，`element.open` 保持 `undefined`，状态读 `data-state`。
这符合仓库既有的 `boolean-default-state-runtime.spec.ts` 契约（覆盖全部 boolean 组件），
但**依赖"`el.open` 一定返回布尔"的代码需要改为读 `data-state`**。

### 3. 未发布但仍在发布集合外的包

`@zeus-js/vite-plugin`（`0.0.5`）、`create-zeus`（`0.1.5`）、`zeus-ui`（`0.0.1`）、
`@zeus-ui/registry`（`0.0.1`）不在 `zeusFixedPackages` 中，本次**保持原版本**。
如果维护者希望它们与 Core 同版，需要把它们加入 fixed 组——这是配置变更，不是版本号变更。
