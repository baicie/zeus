所以 vendor 构建**等价于在冻结 SHA 上构建**，这一点上一份报告没有核实就写了 `commit` 不同，属于漏检。

### 5.1 验证过程中排除的三个假信号

诚实记录，避免后人重复踩：

1. **overlay 元素点击不到**。在官方主题 CSS 下，`zw-dialog-overlay` **没有任何样式**（`packages/themes/src/components/dialog.css` 不包含 overlay 选择器），`position: static`、高 22.5px。视觉上的遮罩是 `zw-dialog-content` 自己的 `position: fixed; inset: 0` 画的。因此测试改为点击 content 的留白区——这才是用户实际点的地方。
2. **WebKit 里普通 `<button>` 按 Tab 就跳 body**。空白页对照实验证实：这是 Playwright 附带的 WebKit 默认不启用 macOS「全键盘控制」，与组件无关。改用 `Shift+Tab` 环绕断言，三引擎一致。
3. **Chromium 的 favicon 404**。是消费者 HTML 缺图标，不是组件。已通过 `data:` favicon 消除，而不是放宽断言。
