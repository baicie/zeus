## 2. 删除项逐个说明

只有四项内容被真正删除，每一项都有理由：

### 2.1 §5.3 "推荐的 IR 结构"（11 个类型名）

原文列举 `TemplateIR`、`TextBindingIR`、`AttrBindingIR` 等 11 个名字。

**删除理由：** 实际 IR 在 `ir.rs`（505 行），文档列举的名字与代码不完全
对应。保留一份**手抄的类型清单**就是"同一事实两处声明"，必然漂移——
这正是本轮审计在 §6.1 发现的同类问题。

**替代：** `docs/architecture/compiler/ir-contract.md` 是 IR 的权威描述。

### 2.2 §6.1 "包拆分建议"（8 个包名）

原文列 `zeus`/`core`/`runtime-dom`/`runtime-wc`/`compiler-shared`/
`compiler-babel`/`vite-plugin`/`types`。

**删除理由（这是真实缺陷）：** 其中三个包**已经不存在**：

```
compiler-babel   MISSING
runtime-wc       MISSING
types            MISSING
```

且该表与 §14 的六域表**对同一件事作出两种不同声明**。
§14 是准确的（`check:structure` 强制校验），§6.1 是 R16.0 之前的遗留。

**替代：** §4 的六域表，唯一声明。

### 2.3 §10 "MVP 路线图"（MVP-0 到 MVP-7）

**删除理由：** 八个阶段**全部交付完毕**。仓库处于 `0.2.0-rc.3`，
Rust 编译器、Web Components、Light DOM 投影、HMR、SSR 都已实现。
把它留在根级 Agent 指令里会让 agent 误以为项目还在早期阶段。

**保留：** git 历史；`docs/internal/` 下的阶段记录。

### 2.4 §12 中"SSR / hydration"两项

原文把 SSR、hydration、partial hydration 列为非目标。

**删除理由（过期声明）：** 仓库已有：

```
packages/core/runtime-ssr/
crates/zeus_compiler/src/analysis/hydration.rs
crates/zeus_compiler/src/support/hydration.rs
docs/api/runtime-ssr.md
```

编译器的 `TransformTarget::Ssr` 是一等目标。继续声称它是非目标，
会让 agent 拒绝实现已经存在的能力。

**保留：** 其余 5 项非目标（样式系统、组件生态、Suspense、JS 魔法、
全局变量重定义）。
